      How the numbers are made

      Forecast

      ECMWF IFS at 0.25°, the run issued the day before (Open-Meteo archive). The same forecast a site manager would have had the evening before.

      Heat index

      Wet-bulb globe temperature in sun by the Liljegren method. The NIOSH limit for heavy work (415 W) is 26.6 °C WBGT.

      Scoring
