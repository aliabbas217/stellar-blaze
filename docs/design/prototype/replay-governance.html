What proves it, in the build

These tests fail the build if the refusal, the audit row or the purpose limits ever stop holding. Names are as designed; the tests land with the governance build.

  • test_employer_has_no_route_to_individual_riskEvery employer-role request for one worker's risk gets 403 problem+json, whatever the purpose.
  • test_refusal_writes_audit_rowEach refusal appends an audit row the worker can see.
  • test_purpose_limitation_no_export_joins_stop_events_to_a_named_workerNo export joins stop events or plan adherence to a named worker.
  • test_individual_data_never_reaches_supervisor_or_employer_viewsSupervisor and employer views carry no individual data.
  • test_personal_fields_rejected_by_the_managed_llm_adapterAcclimatisation and juvenile fields are typed Personal and cannot reach a hosted language model.
  • import contract: sb.employer must not import sb.healthA structural check that the employer code has no path to health data at all.
