# Stellar Blaze

Stellar Blaze is a heat-stress early-warning system for outdoor workers in the UAE, built for Challenge 07 (climate-resilient worker health) of the Future Health Challenge. It turns weather observations and archived forecasts into an hourly heat-stress risk estimate (WBGT, ISO 7933 predicted heat strain, NIOSH limits and thermal work limit) and delivers tiered alerts before conditions become dangerous, with worker protection ranked ahead of productivity.
